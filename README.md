# What is Version Control?
version control is a system that tracks and manages changes to software code over time. 
# What is Git?
Git is a free and open-source distributed version control system designed to track changes in source code or files over time.
# What is GitHub?
GitHub is a cloud-based web platform used by developers to store, share, and manage their software code.
# What is Git Bash?
Git Bash is a command-line application for Microsoft Windows environments that provides an emulation layer for a Git command-line experience. 
# What are the main parts of GitHub?
The main parts of GitHub are its core components that let developers store, share, and work on code together.
